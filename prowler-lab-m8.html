Module 8

Final check and clean-up

Confirm you can run, read and act on Prowler results across all 10 use cases, take the final assessment, then remove every lab resource.

Covers: all 10 use cases and all 7 frameworksTime: about 60 minutesCost: returns to zero after clean-up

Limits of what Prowler checks in this module

  • The final scan shows the project's state at that moment. New resources or changes made later need a new scan.
  • Turning off a trial service changes the result of its checks. Run a scan again after any change you want to record.

Step 2: Remove every lab resource

After you pass the final assessment below, remove the lab resources so they stop costing money. Your cleanup.sh should now look like this. Compare it with your own file, then run it.

cleanup.sh (complete)
#!/usr/bin/env bash
# sf-secure-store — removes every lab resource
# Each module adds its own block directly BELOW the "set +e" line,
# so that the newest resources are removed first.
cd "$(dirname "$0")"
source ./env.sh
set +e   # keep going if a resource is already gone
# --- Module 6: Network Protection and Application Firewall ---
aws wafv2 disassociate-web-acl "${A[@]}" \
  --resource-arn "arn:aws:apigateway:$AWS_REGION::/restapis/$API_ID/stages/prod"
LOCK=$(aws wafv2 get-web-acl "${A[@]}" --name "$PROJECT-web-acl" --scope REGIONAL \
  --id "${WEB_ACL_ARN##*/}" --query LockToken --output text)
aws wafv2 delete-web-acl "${A[@]}" --name "$PROJECT-web-acl" --scope REGIONAL \
  --id "${WEB_ACL_ARN##*/}" --lock-token "$LOCK"
aws apigateway delete-rest-api "${A[@]}" --rest-api-id "$API_ID"
aws ec2 delete-flow-logs "${A[@]}" --flow-log-ids "$FLOW_LOG_ID"

# --- Module 5: Key Management for Encryption ---
aws ec2 delete-volume "${A[@]}" --volume-id "$VOLUME_ID"
aws s3 rm "s3://$DATA_BUCKET" --recursive "${A[@]}"
aws s3api delete-bucket "${A[@]}" --bucket "$DATA_BUCKET"
aws kms delete-alias "${A[@]}" --alias-name "alias/$PROJECT-data"
aws kms schedule-key-deletion "${A[@]}" --key-id "$KEY_ID" --pending-window-in-days 7
# EBS default encryption stays on: it is the recommended setting for every account

# --- Module 4: Credentials Protection and Permissions Analysis ---
aws accessanalyzer delete-analyzer "${A[@]}" --analyzer-name "$PROJECT-analyzer"
aws iam remove-user-from-group "${G[@]}" --group-name "$PROJECT-developers" --user-name "$PROJECT-dev"
aws iam detach-group-policy "${G[@]}" --group-name "$PROJECT-developers" \
  --policy-arn "arn:aws:iam::$ACCOUNT_ID:policy/$PROJECT-deploy"
aws iam detach-user-policy "${G[@]}" --user-name "$PROJECT-dev" \
  --policy-arn "arn:aws:iam::$ACCOUNT_ID:policy/$PROJECT-deploy"
aws iam delete-group "${G[@]}" --group-name "$PROJECT-developers"
aws iam delete-login-profile "${G[@]}" --user-name "$PROJECT-dev"
aws iam delete-user "${G[@]}" --user-name "$PROJECT-dev"
for v in $(aws iam list-policy-versions "${G[@]}" --policy-arn "arn:aws:iam::$ACCOUNT_ID:policy/$PROJECT-deploy" \
           --query 'Versions[?IsDefaultVersion==`false`].VersionId' --output text); do
  aws iam delete-policy-version "${G[@]}" --policy-arn "arn:aws:iam::$ACCOUNT_ID:policy/$PROJECT-deploy" --version-id "$v"
done
aws iam delete-policy "${G[@]}" --policy-arn "arn:aws:iam::$ACCOUNT_ID:policy/$PROJECT-deploy"
aws secretsmanager delete-secret "${A[@]}" --secret-id "$PROJECT/db-password" --force-delete-without-recovery
aws lambda delete-function "${A[@]}" --function-name "$PROJECT-rotate"
aws iam delete-role-policy "${G[@]}" --role-name "$PROJECT-rotation-role" --policy-name rotate-db-password
aws iam detach-role-policy "${G[@]}" --role-name "$PROJECT-rotation-role" \
  --policy-arn arn:aws:iam::aws:policy/service-role/AWSLambdaBasicExecutionRole
aws iam delete-role "${G[@]}" --role-name "$PROJECT-rotation-role"
aws lambda delete-function "${A[@]}" --function-name "$PROJECT-orders"
aws iam delete-role-policy "${G[@]}" --role-name "$PROJECT-app-role" --policy-name read-db-password
aws iam detach-role-policy "${G[@]}" --role-name "$PROJECT-app-role" \
  --policy-arn arn:aws:iam::aws:policy/service-role/AWSLambdaBasicExecutionRole
aws iam detach-role-policy "${G[@]}" --role-name "$PROJECT-app-role" \
  --policy-arn arn:aws:iam::aws:policy/AdministratorAccess
aws iam delete-role "${G[@]}" --role-name "$PROJECT-app-role"

# --- Module 3: Vulnerability Management and Application Security Testing ---
aws inspector2 disable "${A[@]}" --resource-types EC2 ECR LAMBDA LAMBDA_CODE
aws lambda delete-function "${A[@]}" --function-name "$PROJECT-report"
aws iam detach-role-policy "${G[@]}" --role-name "$PROJECT-lambda-role" \
  --policy-arn arn:aws:iam::aws:policy/service-role/AWSLambdaBasicExecutionRole
aws iam delete-role "${G[@]}" --role-name "$PROJECT-lambda-role"
aws ecr delete-repository "${A[@]}" --repository-name "$PROJECT/api" --force
aws ec2 terminate-instances "${A[@]}" --instance-ids "$INSTANCE_ID"
aws ec2 wait instance-terminated "${A[@]}" --instance-ids "$INSTANCE_ID"
aws ec2 delete-security-group "${A[@]}" --group-id "$SG_ID"
aws iam remove-role-from-instance-profile "${G[@]}" \
  --instance-profile-name "$PROJECT-ec2-profile" --role-name "$PROJECT-ec2-role"
aws iam delete-instance-profile "${G[@]}" --instance-profile-name "$PROJECT-ec2-profile"
aws iam detach-role-policy "${G[@]}" --role-name "$PROJECT-ec2-role" \
  --policy-arn arn:aws:iam::aws:policy/AmazonSSMManagedInstanceCore

# --- Module 2: Threat Detection and Cloud Security Posture Management ---
aws iam delete-group-policy "${G[@]}" --group-name prowler-scanners --policy-name prowler-securityhub

  --product-subscription-arn "arn:aws:securityhub:$AWS_REGION:$ACCOUNT_ID:product-subscription/prowler/prowler"
aws securityhub disable-security-hub "${A[@]}"
aws guardduty delete-detector "${A[@]}" --detector-id "$DETECTOR_ID"

# --- Module 1: Configuration Monitoring ---
aws configservice stop-configuration-recorder "${A[@]}" --configuration-recorder-name default

aws configservice delete-configuration-recorder "${A[@]}" --configuration-recorder-name default

aws s3 rm "s3://$LOG_BUCKET" --recursive "${A[@]}"
aws s3api delete-bucket "${A[@]}" --bucket "$LOG_BUCKET"
aws s3 rm "s3://$ACCESS_LOG_BUCKET" --recursive "${A[@]}"

# --- Module 0: scan user, group and budget (remove only when you have finished the course) ---
for k in $(aws iam list-access-keys "${G[@]}" --user-name prowler-scan --query 'AccessKeyMetadata[].AccessKeyId' --output text); do
  aws iam delete-access-key "${G[@]}" --user-name prowler-scan --access-key-id "$k"

aws iam remove-user-from-group "${G[@]}" --group-name prowler-scanners --user-name prowler-scan
aws iam delete-user "${G[@]}" --user-name prowler-scan
aws iam detach-group-policy "${G[@]}" --group-name prowler-scanners \

The Module 0 block deletes the scan user and the budget. If you want to keep scanning your account with Prowler after the course, delete that block from the script before you run it.

Step 3: Check that nothing is left

verify-clean.sh
#!/usr/bin/env bash
# Lists anything from the lab that is still in the account. Empty output = clean.
cd "$(dirname "$0")"
source ./env.sh

echo "== S3 buckets";          aws s3api list-buckets "${G[@]}" --query "Buckets[?starts_with(Name, '$PROJECT')].Name" --output text
echo "== EC2 instances";       aws ec2 describe-instances "${A[@]}" --filters "Name=tag:Name,Values=$PROJECT-*" \
                                 "Name=instance-state-name,Values=pending,running,stopping,stopped" --query 'Reservations[].Instances[].InstanceId' --output text
echo "== EBS volumes";         aws ec2 describe-volumes "${A[@]}" --filters "Name=tag:Name,Values=$PROJECT-*" --query 'Volumes[].VolumeId' --output text
echo "== Security groups";     aws ec2 describe-security-groups "${A[@]}" --filters "Name=group-name,Values=$PROJECT-*" --query 'SecurityGroups[].GroupId' --output text
echo "== Lambda functions";    aws lambda list-functions "${A[@]}" --query "Functions[?starts_with(FunctionName, '$PROJECT')].FunctionName" --output text
echo "== ECR repositories";    aws ecr describe-repositories "${A[@]}" --query "repositories[?starts_with(repositoryName, '$PROJECT')].repositoryName" --output text
echo "== IAM roles";           aws iam list-roles "${G[@]}" --query "Roles[?starts_with(RoleName, '$PROJECT')].RoleName" --output text
echo "== IAM users";           aws iam list-users "${G[@]}" --query "Users[?starts_with(UserName, '$PROJECT') || UserName=='prowler-scan'].UserName" --output text
echo "== REST APIs";           aws apigateway get-rest-apis "${A[@]}" --query "items[?name=='$PROJECT-api'].id" --output text
echo "== WAF web ACLs";        aws wafv2 list-web-acls "${A[@]}" --scope REGIONAL --query "WebACLs[?Name=='$PROJECT-web-acl'].Name" --output text
echo "== Secrets";             aws secretsmanager list-secrets "${A[@]}" --query "SecretList[?starts_with(Name, '$PROJECT')].Name" --output text
echo "== KMS alias";           aws kms list-aliases "${A[@]}" --query "Aliases[?AliasName=='alias/$PROJECT-data'].AliasName" --output text
echo "== CloudTrail trail";    aws cloudtrail describe-trails "${A[@]}" --query "trailList[?Name=='$PROJECT-trail'].Name" --output text
echo "== Config recorder";     aws configservice describe-configuration-recorder-status "${A[@]}" --query 'ConfigurationRecordersStatus[?recording].name' --output text
echo "== GuardDuty detector";  aws guardduty list-detectors "${A[@]}" --query 'DetectorIds' --output text
echo "== Access Analyzer";     aws accessanalyzer list-analyzers "${A[@]}" --query "analyzers[?name=='$PROJECT-analyzer'].name" --output text
echo "== Inspector";           aws inspector2 batch-get-account-status "${A[@]}" --query 'accounts[0].state.status' --output text
chmod +x verify-clean.sh
./verify-clean.sh

Every section should print nothing, except Inspector, which should show DISABLED, and CloudTrail trail and Config recorder, which should be empty. If something is still listed, run ./cleanup.sh again: some resources, such as the security group, can only be deleted after the resources that use them are gone.

# Last scan, to record the cleaned-up state
pscan --service ec2 awslambda s3 kms -o scans/m8-after-cleanup

Step 4: Turn off trial services and stop Prowler Local Server

The clean-up script already turned off GuardDuty, Security Hub, Amazon Inspector and the AWS Config recorder in ap-south-1. Check the AWS console for each service to confirm, especially if you turned any of them on in other regions.

cd ~/prowler-local-server
docker compose down          # stops and removes the containers
# docker compose down -v     # also deletes the stored scan data
Changing a service's state changes the result of its checks. If you keep scanning your account later, a check such as guardduty_is_enabled will fail again now that GuardDuty is off. Run a new scan after any change you want to record.

What to do next

  • Run Prowler against every region of an account you manage, not only ap-south-1, by removing the -f option.
  • Schedule a weekly Prowler scan and keep the reports as dated evidence.
  • Read the Manual requirements of the frameworks your clients care about, and list the documents and processes that would answer each one.
  • Look at the failures you did not fix in this course, such as root user MFA or WAF logging, and practise fixing them in a lab account.
